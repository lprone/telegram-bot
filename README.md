# Telegram Bot

This project is a Telegram bot built using Python. It provides a baseline to interact with users through the Telegram platform.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/lprone/telegram-bot.git
   cd telegram-bot
   ```
2. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
To run the bot, execute the following command:
```bash
python main.py
```
